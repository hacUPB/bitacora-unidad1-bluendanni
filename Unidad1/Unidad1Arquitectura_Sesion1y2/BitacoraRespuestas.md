# Respuestas a Bitácora de la sesión 1 y 2. 

## Sesión 2, Actividad 2.
> ¿Qué diferencia hay entre los datos almacenados en la memoria ROM y en la RAM?

-ROM: 
1. Guarda instrucciones.
2. La CPU la consulta usando el PC
3. Contiene el programa
4. Se considera memoria de instrucciones
5. No se modifica durante la ejecución normal

-RAM:
1. Guarda datos y variables
2. La CPU la consulta usando direcciones
3. Contiene resultados y valores temporales
4. Se considera memoria de datos
5. Puede leerse y escribirse
